# Online Store

Учебный проект интернет-магазина на Django.

## О проекте

Проект представляет собой основу интернет-магазина, которая будет развиваться и дополняться в ходе дальнейших домашних заданий курса.

На текущем этапе реализованы:
- главная страница;
- страница контактов;
- маршрутизация Django;
- HTML-шаблоны с использованием Bootstrap;
- подключение статических файлов Bootstrap.

## Технологии

- Python 3.13
- Django 6.1
- Bootstrap 5.3.8
- Poetry
- Git / GitFlow

## Установить зависимости:

``` 
poetry install
```

## Запуск

Запустить сервер разработки:
```bash
poetry run python manage.py runserver
```
После запуска проект будет доступен по адресу:

http://127.0.0.1:8000/
